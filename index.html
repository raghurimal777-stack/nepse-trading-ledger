How to use

1. Add BUY transactions. 2. Add SELL transactions. 3. Enter current market price in Portfolio to see unrealized P/L. 4. Use Journal for Elliott Wave / SMC / ICT setup notes.

Fee / Tax logic in V2.4 Fixed

• Brokerage: based on turnover slab
• SEBON transaction fee: 0.015%
• DP charge: Rs. 25 on BUY and Rs. 25 on SELL
• CGT: SELL only and only on capital gain
• FY 2083/84: ≤365 days = 10%, >365 days = 7.5%
