# NEPSE Trading Ledger V1

A simple browser-based NEPSE trade journal/ledger.

## Run
Open `index.html` in a modern browser.

## Deploy
Upload this folder/repository to GitHub, then import the GitHub repository into Netlify.

## Notes
- Data is stored in browser localStorage in V1.
- Export a JSON backup regularly.
- Current market prices are entered manually.
- Verify current Nepal brokerage/statutory fee rules before using for accounting.
